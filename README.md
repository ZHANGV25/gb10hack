## The brief

Build a **locally-run AI business agent** on Dell Pro Max hardware with NVIDIA's GB10
processor. Everything runs **on-device — no cloud APIs**.

Per the event page, the stack is `OpenClaw + NVIDIA NemoClaw + OpenShell`.

## Rules

- Teams of 2–4 builders.
- Demo must run **entirely locally** on the Dell Pro Max with GB10 — no cloud API calls.
- Submit the working demo through the BuilderBase portal before the deadline.
- Top 8 teams pitch live to judges.
- Pre-load models onto a USB/external drive — venue WiFi is not sufficient to pull them.

## Prizes

2. **2nd** — Dell laptop, per team member
